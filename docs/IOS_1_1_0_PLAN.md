## 二、完整功能与界面设计

### 1. 下载入口与分享流程

统一剪贴板、手动粘贴、系统分享、内置浏览器四种入口，全部进入同一套解析和任务流程。

- 剪贴板自动下载默认开启，可关闭；仅在启动、回前台及前台剪贴板变化时处理，保留变化去重和应用自身复制跳过。
- 分享收件箱先处理，再检查剪贴板；相同正在运行的笔记合并到现有任务，并直接定位该任务。
- 手动输入支持完整分享文案、多链接和批量粘贴，提交前显示识别出的笔记数量与无效项。
- 每个入口提供“直接下载”“选择内容”“仅保存笔记”三种动作；“提取文案”保留为快捷操作。
- 分享扩展使用轻量界面选择动作，先可靠写入 App Group 收件箱，再尝试打开主应用；跳转失败时明确显示“已加入，打开应用继续”，避免重复提交。
- 分享扩展与剪贴板导入共用请求身份，主应用持久入队后才确认消费。

### 2. 账号、内置浏览器与真正的网页提取

补齐登录账号卡、持久会话和网页数据提取能力，形成可供下载使用的完整链路。

- 设置顶部显示**当前登录账号**的头像、昵称、小红书号和会话状态，提供登录、重新验证、退出入口；与笔记作者信息分开保存。
- 采用持久 WKWebView 会话，支持后退、前进、刷新、页面缩放和系统打开。
- 网页提取直接读取当前页面的结构化笔记数据，接入统一模型；不再只取当前 URL 后重新请求一次。
- 浏览器底部固定提供“下载本篇”“选择内容”“保存文案”；页面需要登录或验证时，完成后可原地重试。
- 从作者主页、收藏、专辑、搜索和推荐页面提取**当前已加载的笔记链接**，进入带缩略图的批量选择面板；显示“仅包含已加载内容”，由用户手动滚动加载后再次提取。吸收上游脚本列表提取与选择交互，不增加自动滚动采集。
- 手动 Cookie 作为高级入口存入 Keychain，按域名管理；请求前同步适用的网页会话，退出账号后清除对应会话。
- 登录失效显示可操作提示，点击返回登录页，完成后继续原任务。

### 3. 解析规则、作者资料与上游同步

建立唯一解析入口，普通链接和网页提取输出相同结果。

- 完整覆盖 `.com`、`.cn` 短链接、RedNote、移动端／桌面笔记结构、分享文字和必要访问参数。
- 保持按目标笔记 ID 匹配，避免把页面推荐笔记、头像或装饰图片当成下载内容。
- 纳入上游对特殊字符、`undefined`、空 Map／Set 和字段缺失的兼容修复；按数据项独立回退，单张图片缺少字段不影响其他图片。归一化处理必须保留正文中的字面文本，不能全局误替换文字内容。
- 图片依次利用原始地址、`fileId`、页面候选；视频保留原始资源和各档清晰度、编码、码率、体积、备用地址。
- 作者资料分别保存昵称、内部 UID、公开小红书号、主页地址和头像；缺少公开小红书号时允许从作者主页补全，补全失败不阻塞媒体下载。
- 作者头像继续保存 **192px 本地副本**，满足现有显示尺寸，离线可用；头像更新成功后替换缓存。
- 点击头像、昵称和小红书号组成的整块区域打开作者主页：优先系统通用链接，无法打开时使用内置浏览器。
- 新下载和旧记录共用作者信息；旧记录可手动“更新笔记资料”，只补全资料，不重新下载媒体。
- 缺失作者时显示“作者信息未获取”，提供重试，避免再次把“小红书笔记”显示成作者昵称。

### 4. 媒体策略、Live Photo 与 HDR

补齐图片格式、视频策略、封面、评论图和文案保存，同时把媒体真实性作为基本要求。

| 项目 | 确定行为 |
| --- | --- |
| 普通图片 | 默认原件；可选择服务器提供的 JPEG、PNG、WebP、HEIC、AVIF。按实际响应识别格式，不仅修改扩展名。 |
| 视频 | 默认原始资源优先；提供分辨率、码率、较小体积、H.264 兼容优先，以及单任务手动选择。 |
| 视频封面 | 默认关闭，可全局开启或单任务勾选。 |
| 评论／回复配图 | 默认关闭；只提取当前数据中已加载的图片，独立分组、独立选择，并显示加载范围。 |
| Live Photo | 默认 Apple Live Photo；另有组件分别保存、仅静态图片。合成使用原始静态组件，普通图片格式偏好不改变实况组件。 |
| 文案 | 始终保存在本地笔记记录中；外部输出可选无、TXT、Markdown、两者。 |
| 仅保存笔记 | 不下载原媒体、不申请照片权限；保存标题、正文、作者、话题、日期和来源，可随后补下载。 |

媒体处理要求：

- 指定格式或画质不可用时回退到可用资源，任务中显示实际结果与回退原因。指定非原件格式或兼容视频规格时说明可能影响 HDR／质量，不隐瞒实际保存类型。
- 选择面板先加载缩略图和已知规格；未选择的媒体不下载原件，未知体积显示“未知”。
- 图片保留颜色描述、方向、HDR 辅助数据和增益图；视频保留原始 HDR 元数据与音视频样本。
- Live Photo 优先复用已有配对标识；需要补写时采用无重编码处理，处理后重新核对配对与媒体属性。
- 无法保留原件质量完成合成时保存可用组件，明确标注“组件已保存，未合成实况”，允许重试失败组件。
- 媒体详情统一显示实际格式、尺寸、体积、时长、编码及可证实的 HDR／Live Photo 信息；P3、HEVC、10bit 不单独作为 HDR 标记依据。
- 保留已经修复的相册信息清理逻辑，正文留在笔记记录和文案文件中，避免再次写入异常的图片描述信息。

### 5. 任务中心与逐文件管理

任务卡片负责快速判断，任务详情负责查看和处理每个资源。

- 下载页按进行中、待处理、已完成分组；支持搜索、状态筛选、批量暂停、继续、重试和移除记录。
- 明确区分排队、解析、等待选择、传输、保存、暂停、部分完成、失败、取消，以及需要登录／授权／选择目录的阻塞原因。暂停任务纳入待处理筛选。
- 详情在解析完成后就显示稳定媒体槽位，每项显示类型、选中规格、字节进度、状态、保存位置和错误。
- 总进度聚合全部资源，速度按实际传输字节计算；未知总大小时显示不确定进度，不拼出虚假的百分比。
- 默认一个笔记执行、笔记内最多四个实际传输；待选择或待授权任务不占用执行名额。
- 暂停与取消分开；重试只处理失败或未保存资源，成功结果继续保留。
- 下载成功但保存失败的原件保留，重新授权或重选目录后直接保存。
- 资源地址过期时重新解析并按稳定资源身份匹配；候选全部失败后才把对应资源判为失败。
- 每个任务保存提交时的完整设置快照；恢复后保持原选择、命名时间、文件名和输出策略。登录凭据由会话管理提供，不复制进快照。
- 新增“查看笔记”“复制链接”“网页打开”“只重试失败项”等直接动作。

后台继续使用 URLSession；解析、交互和部分媒体处理按系统允许的执行时间恢复。用户主动强退后的任务在再次打开时提供恢复入口，不把后台能力描述为持续常驻。

### 6. 笔记信息流与阅读体验

笔记成为独立于任务历史、照片权限的本地内容库。

- 手机默认双列瀑布流；卡片展示封面、两行标题、作者头像昵称、媒体类型和本地喜欢状态。
- 保留“发现／收藏”；“发现”表示本机全部笔记。工具栏菜单提供作者、合集、排序和批量管理。
- 支持按标题、正文、话题、昵称、公开小红书号和作者备注搜索；按保存时间或发布时间排序。
- 作者筛选页汇总该作者的已保存笔记，支持备注和打开原作者主页。
- 增加本地合集：新建、重命名、删除、批量加入／移出；删除合集保留笔记。
- 详情显示媒体分页、完整标题、正文、蓝色话题、作者、发布时间及来源；喜欢、收藏仅保存在本机。
- 文案支持选择复制、全文复制；话题可搜索本地相关笔记。自身复制不触发自动下载。
- 仅文案笔记使用正文摘要卡片；媒体无访问权限时显示可恢复状态，仍能阅读文案和作者信息。
- 任务详情和笔记详情共用媒体查看器，统一缩放、播放、分享、删除及信息面板。
- 删除操作明确区分移除下载记录、移出本地笔记、移出专用相册和删除系统照片；批量删除展示范围与数量。

### 7. 转场与手势专项保护、回归和修正

当前 build 16 已获得用户满意反馈，必须以其外观和手感为保护基线。这部分单独验收，保留可跟手、中断和甩动的交互目标；仅修复当前仍可复现的问题。

- **信息流到详情**：以整个卡片为起点，图片、标题、背景连续展开；作者和正文平滑接入，源卡片在接管期间隐藏。
- **详情图片到全屏**：复用当前清晰画面，从实际显示位置移动到屏幕中心；黑色背景随进度渐入，关闭时反向恢复。
- **拖动返回**：位移、缩放、背景和圆角直接跟随手势，松手后根据位置与速度完成或弹回；弹回过程中可再次抓住。
- **左边缘返回**：保留左侧边缘手势；与媒体横向翻页、图片缩放和正文滚动明确仲裁。
- **防止内容跟着滚动**：返回手势接管后冻结正文和媒体分页的滚动位置；取消返回时恢复原偏移。正文中部的普通竖向拖动继续用于阅读。
- **四角裁切**：整张详情页面统一使用连续圆角遮罩，图片、文字、顶部和底部工具栏全部参与裁切。
- **底栏完整层级**：由根容器统一协调完整系统标签栏，包括玻璃背景、全部图标文字和选中状态；返回中整体显现，避免只抬高选中项。保留当前真实原生底栏分支方案，不回退为单独复制选中项或不完整快照。
- **结束帧交接**：转场层、真实页面、源卡片和底栏在同一次完成处理中交接；缩小关闭前不先重置图片状态，消除跳回正常大小和残留白块。
- 返回目标不在可见范围或已删除时使用当前位置淡出，避免飞向错误卡片。
- 动画过程中禁止误触底层信息流和标签切换；开启“减少动态效果”时采用短淡入淡出。

### 8. Files 归档、命名与重复下载

默认继续把媒体原件保存到 Photos 专用相册，Files 归档由用户主动开启。

- 保存位置支持“照片”“文件”“照片与文件”；新增文件目的地通过系统目录选择器授权，设置展示可读位置和重新授权入口。
- 文件归档支持按作者、按笔记分目录；默认作者目录包含稳定 UID，笔记目录包含笔记 ID，避免同名冲突。
- 作者备注影响显示和新建归档名称，已有文件不自动批量移动。
- 命名编辑器提供占位符插入、预设、真实示例预览、错误定位和恢复默认。
- 补齐 `{redId}`、发布和下载日期格式；保留已有占位符兼容性。使用原始时间值格式化，不从已显示的短日期反推时间。
- 文件名一次生成并随任务保存；日期、时区及补全的小红书号在暂停、恢复和跳过检查时保持一致。
- 所有目录和文件名经过路径字符清理、长度控制和重名处理，写入限定在授权目录内。
- 智能跳过默认关闭；开启后同时检查笔记／媒体身份、所需规格、输出目的地和实际可访问结果。
- Photos 有限访问导致无法确认时显示“无法核对”，不能直接当作文件丢失或已经保存。
- 写入发布时间默认关闭；开启后应用到新保存资产的日期，Photos 按资源创建日期设置，Files 尽力写入并报告实际结果。

### 9. 设置、通知、导出与日常维护

设置使用原生分组列表，分为账号、媒体、归档与命名、网络与会话、交互与通知、数据与存储、关于。

- 网络默认请求超时 45 秒、自动重试三次；提供范围校验和重置。
- 笔记解析请求间隔默认两秒，可设为 0—30 秒；只控制页面解析请求，不限制媒体并行，限流响应遵循服务端等待要求。
- 提供系统网络、HTTP、SOCKS5 配置及连接检查；“媒体使用应用代理”独立开关，默认关闭。URLSession 与 WKWebView 使用公开代理配置接口，并在创建会话前应用配置。“关闭应用代理”表示仍遵循系统网络，不宣称绕过系统 VPN。
- 完成／失败通知与诊断通知分开，用户开启正常通知时再申请授权；点击通知进入任务。
- 触感反馈默认开启，可关闭；覆盖选择、收藏、成功、失败和删除确认，不随进度高频触发。
- 常亮默认关闭，开启后仅在前台执行任务时生效。
- 支持跟随系统、浅色、深色；补齐简体中文、繁体中文和英文。
- 缓存页显示预览、头像、待保存原件的占用；可清理预览，保护活动及未保存原件。预览磁盘缓存上限 512MiB。
- 导出 JSON／CSV 下载记录；批量原件导出提供 ZIP，内含原文件、文案和资源清单，Live Photo 保留两个组件及配对关系。
- 增加版本化资料备份与导入，包含笔记、作者、合集、收藏、设置和头像；不包含登录凭据。原媒体通过原件导出单独保存。
- 备份导入按笔记身份合并；同机尝试复用有效 Photos 引用，跨设备显示待关联状态，不自动重新下载。
- 关于页提供版本、更新说明、开源信息、手动检查更新；自动检查每日最多一次，有新版才提示，打开下载页后由用户自行更新。
- 错误提示附带对应动作，如登录、重新授权、重选目录、释放空间或重试失败项；记录与诊断导出隐藏 Cookie、本机私人路径和带访问凭据的地址。

## 三、数据模型、接口与升级迁移

按职责拆开解析、会话、任务、媒体保存和界面，避免继续扩大单个下载器与页面文件。

| 模型／接口 | 必须补齐的内容 |
| --- | --- |
| `ResolvedNote` | 原始发布时间、作者资料、话题、正文、媒体列表与数据来源；允许无媒体笔记。 |
| 资源与候选规格 | 稳定身份、正文／封面／评论角色、编码、尺寸、体积、备用地址及显式实况配对。 |
| 下载策略快照 | 媒体选择、规格、Live Photo、命名时间、输出位置、网络策略和文案格式。 |
| 任务与资源结果 | 任务阶段、逐资源状态、检查点、暂存文件、保存引用、失败原因及重试代次。 |
| 本地笔记与作者 | 独立于任务历史，保存正文、作者、媒体关联、喜欢、收藏和合集。 |
| 保存目的地 | 统一 Photos 与 Files 保存结果，支持分别重试，不重复写入已经成功的目的地。 |

持久化采用 **SwiftData 与串行数据访问 actor**。进度只更新内存状态并节流写入；状态变化、选择确认和保存结果立即落盘，替代当前高频整份 JSON 重写。

迁移要求：

- 升级前保留旧 JSON 和设置备份；迁移成功并完成数量、身份和关联核对后再切换新存储。
- 保留任务 ID、创建时间、文件名、Photos 引用、选择状态、喜欢和收藏。
- 同一笔记的多个历史任务关联到同一笔记条目，保留各次下载历史。
- 迁移不联网、不重新下载、不修改系统照片；缺失资料标为待补全。
- 迁移失败保留旧数据和可重试入口，不创建空库覆盖原记录。
- 分享扩展继续只写收件箱，数据库和账号信息由主应用管理。
- 取消与重试使用独立执行代次，旧回调不能覆盖新任务结果。

## 四、验证标准与最终交付

验证覆盖整条用户流程，已有通过记录继续作为回归基础，新增能力单独记录结果。

| 范围 | 验收场景 |
| --- | --- |
| 解析与会话 | 新旧短域名、RedNote、多链接、目标匹配、特殊字符、缺失字段、登录失效、网页提取、已加载列表和评论图片。 |
| 媒体 | 原图、各格式响应、视频规格与候选回退、多张实况配对、组件失败、HDR 元数据保留、相册信息显示。 |
| 任务 | 并行进度、暂停继续、取消后重试、地址过期、部分保存、断网、Range 异常、重新启动恢复、保存失败后补存。 |
| 数据与文件 | 旧版本迁移、重复导入、有限照片权限、外部删除、目录失效、低空间、备份导入和原件导出。 |
| 界面 | iPhone Air、安全区、横屏、iPad、动态字体、VoiceOver、深色及减少动态效果；操作区域至少 44pt。 |
| 动画 | 整卡展开、标题连续移动、图片展开与收起、左边缘返回、拖动取消后重新接管、正文不误滚动、四角裁切、完整底栏层级及结束帧。 |

动画回归以满意检查点作对照。可运行时保留开关过程和交互返回的逐帧证据，检查用户既往截图中出现过的黑屏、重影、白块、文字覆盖、底栏遮挡与最后一帧跳变；未复现时不为重写动画而重写。

模拟器无法启动时停止反复等待，不以启动故障阻塞安装包交付；可执行测试、编译结果与待真机确认项分别记录。HDR 实际显示、触感、分享冷启动和后台生命周期仍需真机确认，不能用构建成功代替。

最终一次性交付：

- 主应用与分享扩展版本一致的 **1.1.0 arm64 Release IPA**；构建号相对当前版本递增。
- SHA-256、完整更新说明、签名和 App Group 安装说明。
- 功能验收表、已知限制和待真机确认项。
- 更新后的项目文档和上游同步基线。

安装包直接提供给用户，不通过 QQ 代发，不自动推送或发布仓库。用户已授权建立当前基线提交；后续实施按交接提示词在独立工作分支建立本地提交。

## 五、默认值与明确边界

默认保留原件、Apple Live Photo、Photos 专用相册、直接下载和前台剪贴板自动下载；选择下载、封面、评论图片、智能跳过、Files 归档、写入发布时间、常亮与通知默认关闭。已有用户设置在升级时保留。

本次包含多个具体链接和当前网页已加载列表的选择导入；不做个人主页、收藏或专辑的自动无限翻页采集。Android 基线本身也未提供这些列表的全量自动下载。

Android 厂商实况容器、桌面 CLI、API／MCP 服务和独立服务器部署不进入 iOS 客户端范围；未合并 PR 作为参考提案评估，相关文件路径处理和 TLS 校验要求在原生实现中落实。所有适合手机端的参考能力按上述方式完成，界面和系统集成保持 iOS 原生设计。
