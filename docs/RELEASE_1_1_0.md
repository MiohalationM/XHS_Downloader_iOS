## build 26：触感反馈系统、异步存储、Files 归档能力与纯文字批量操作

## build 24：首次登录同步与标题交接

## 完成范围

### 1. 下载入口与分享流程

- 剪贴板、手动粘贴、系统分享、内置浏览器四个入口共用 `ImportRequest` + `DownloadCoordinator.accept` 单一流程。
- 三种动作（直接下载 / 选择内容 / 仅保存笔记）由 `ImportRequest.Behavior` 表达；入口动作优先于全局默认，`.direct` 不会因为「选择下载」设置而变成选择弹窗。
- 手动输入页在提交前显示识别数量，三个动作与「提取文案」并列为按钮。
- 分享扩展改为动作选择界面；先写 App Group 收件箱再尝试跳转；失败显示「已加入，打开应用继续」；二次点击不重复入队。
- 相同笔记正在运行时，`focusExistingTask(for:)` 合并到现有任务并定位。
- 收件箱在任务持久入队后才 `acknowledge`。

### 2. 账号、内置浏览器与网页提取

- 设置顶部账号卡：头像（192px 本地副本）、昵称、小红书号、会话状态点、登录/重新验证/退出。
- `WebSession` 使用 `WKWebsiteDataStore.default()`，与下载请求共享 cookie；`captureAccount` 只在 `loggedIn === true` 且存在 `userInfo.userId` 时记录账号，不读取正在浏览的作者。
- `BrowserView`：持久会话、后退/前进/刷新/缩放/系统打开、进度条。
- 底部固定「下载本篇 / 选择内容 / 保存文案」。
- 「本页笔记」提取当前已加载的 `a[href*="/explore/"]` 与 `/discovery/item/` 链接，去重、最多 200 条，不自动滚动。
- 手动 Cookie：按域名存入 Keychain，可保存/清除，`SessionVault.sanitize` 会丢弃无效键值对。
- 退出登录清除可信域 cookie、`dataRecords` 与 Keychain 条目。

### 3. 解析与作者资料

- 唯一解析入口 `resolveNote`（HTML / 字典两种来源），按目标笔记 ID 匹配，不回退到页面任意图片。
- 图片候选顺序：原始地址 → `fileId` → 页面候选；视频保留原始资源与各档清晰度、编码、码率、体积、备用地址。
- 作者保存昵称、内部 UID、公开小红书号、主页地址与 192px 头像副本；缺失作者显示「作者信息未获取」并可通过 `restoreMissingAuthor` 重试。

### 4. 媒体策略、Live Photo 与 HDR

- `DownloadPolicy`、`downloadInstant` 与命名时区/模板在提交时写入任务快照；重试沿用同一快照，因此文件名、日期和时区保持一致。
- 默认：原件、原始视频优先、封面关、评论图关、Apple Live Photo 合成、保存到照片、不生成文案文件。
- `includes(_:)` 按角色与类型过滤，默认不下载封面/评论图（修复交接文档指出的高风险回归）。
- `applying(_:variantID:)` 在下载链路生效：视频按偏好排序候选，图片非原件时前置服务器格式地址并保留原始回退。
- Live Photo 合成失败时保存两张原件并标注 `error.live_pair`，不谎称已合成。
- 相册信息清理逻辑（`PhotoImportMetadata.prepare`）与原件字节保持不变。

### 5. 任务中心

- 分组：进行中 / 待处理 / 已完成（`TaskGroup`），每种状态恰好属于一组（有测试覆盖）。
- 照片与文件是独立目的地，逐资源分别记录 `DestinationResult`；目录不可用时文件半程记为失败，任务不报完成，暂存原件保留以便只补存失败目的地。
- Live Photo 合成结果单独记录（`merged` / `componentsOnly`），合成失败不计入成功且可重试。
- 搜索、状态筛选、批量暂停/继续/重试失败/移除已完成。
- 详情三段：文件 / 文案 / 资源；资源页显示稳定槽位、角色、状态、字节进度、速度、保存位置与错误。
- `ResourceResult` 逐资源记录，失败项 `retryFailedResources` 只重排失败槽位。
- 未知总大小时只显示已接收字节，不拼百分比。
- 一个笔记执行、笔记内每批最多 4 个并发预取。
- 暂停与取消分开；下载成功但保存失败的原件保留在 `stagedFiles`，重试可直接复用。

### 6. 笔记库

- 笔记保存在独立的 `NoteStore` 中，与任务记录解耦；移除已完成、清空历史、删除任务都不会删除笔记正文、作者、媒体关联或合集收藏。首次启动会把旧任务里的笔记迁移出来。
- 纯文案笔记可打开、删除；Files 保存的媒体也会进入笔记浏览；无照片权限时使用顶部提示条而不是整屏阻断。
- 保留双列瀑布流与原有转场。
- 作者筛选（按稳定 UID 或昵称）、作者备注（仅本机）、本地合集（新建/重命名/删除，删除合集不删除笔记）、排序（保存时间新→旧/旧→新、发布时间新→旧）。
- 搜索覆盖标题、正文、话题、昵称、小红书号与备注。
- 仅文案笔记以摘要卡片显示，不再因缺少照片而消失。

### 7. 动画专项

未修改满意基线的动画实现。回归场景（整卡展开、图片到全屏、拖动返回跟手与中途接管、底栏层级、结束帧交接）在本次交付中保持原样，未做重写。

### 8. Files 归档

- 保存位置：照片 / 文件 / 照片与文件。
- 目录通过系统选择器授权，`ArchiveDirectory` 用 bookmark 保存；失效时设置页提示重新选择。
- 按作者、按笔记分目录（作者目录含 UID，笔记目录含笔记 ID）。
- 命名编辑器：占位符、三个预设、真实文件名预览、错误提示、恢复默认；补 `{redId}` 与发布/下载日期格式；时区显式写入 `NamingPreferences` 并随任务快照。
- 文件名一次生成并写入任务；暂停恢复与智能跳过保持一致。
- 智能跳过默认关闭；命中时记为 `skipped` 而不是再写一份。
- 写入发布时间默认关闭。

### 9. 设置

七组：账号 / 媒体 / 归档与命名 / 网络与会话 / 交互与通知 / 数据与存储 / 关于。

- 超时默认 45 秒（5–180）、重试 3 次（0–10）、请求间隔 2 秒（0–30，0 表示不限速）。每个任务按自身策略快照创建下载器，修改后对后续任务即时生效。
- 代理支持 http/socks5，「媒体使用应用代理」默认关，创建会话前应用配置，可做格式检查。带代理的媒体改走前台会话，因为后台会话无法携带代理配置。
- 完成通知与诊断通知分开；通知点击定位任务。
- 触感默认开，不随进度高频触发。
- 常亮默认关，且只在有进行中任务时生效。
- 外观跟随系统/浅色/深色。
- 「检查更新」读取发布版本并做数值比较，失败时明确提示无法检查。
- 缓存页显示预览、头像、待保存原件占用；可清理预览缓存。
- 导出 JSON/CSV、导出原件 ZIP。ZIP 通过 `PhotoOriginalExporter` 从相册读取真实原件，因此默认「照片」保存的媒体不再缺失；Live Photo 保留两个组件并在 `manifest.csv` 标注 `component`。
- 备份 v2 包含笔记、合集、喜欢、收藏、作者备注、全局设置与作者头像；不含 cookie、代理凭据与目录授权；按笔记身份合并导入。
- 导出会脱敏分享原文、`xsec_token` 等访问参数、媒体地址与归档绝对路径。
- 诊断导出隐藏 Cookie、私人路径与带凭据地址。
- 启动时若任务或笔记加载/迁移失败，立即提示原因而不是显示空库。
